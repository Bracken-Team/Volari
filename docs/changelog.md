# Changelog

All notable changes to Volari are documented here.

## [1.0.0] - 2026-01-03

### Added
- Initial release of Volari GUI
- Modern Tokyo Night-inspired dark theme
- Process analysis with dump and hash capabilities
- Network connections viewer
- Registry browser (HiveScan, HiveList, PrintKey)
- File listing and extraction
- Malware detection tab
- Timeline visualization with interactive charts
- IOC scanner (STIX, OpenIOC, JSON)
- VirusTotal integration
- Investigation queue system
- PDF report generation
- Cross-platform support (macOS, Windows, Linux)
- Auto-investigation feature
- Configurable settings
- Logging panel

### Changed
- Refactored codebase for production quality
- Added proper logging throughout
- Created custom exception hierarchy
- Centralized configuration management

### Fixed
- macOS window styling issues
- Progress bar text contrast
- Button hover state visibility
- Memory leak in plugin execution
